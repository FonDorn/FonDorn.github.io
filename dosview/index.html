FonDorn / dosview

dosview

Any file as binary, hex or text, in 20 code pages — from CP437 and CP866 to UTF-16 — in a DOS text-mode look. Files of any size, search by text or bytes, go to offset, record formatting. For iPhone, iPad and Android.

Support

Found a bug, or missing a code page or a feature? Write to crespo8800@gmail.com, or open an issue: github.com/FonDorn/FonDorn.github.io/issues. Please add your device, its system version and the app version (About in the app).

Questions

How do I open a file? Open on the home screen picks from Files, Photos picks a photo or a video. Or send a file to dosview from any app with "Open in…" (Android: "Open with") or the share sheet.

How do I search for bytes? Switch the search prompt to HEX, or start with x:, e.g. x:89 ?? 4E 47, where ?? matches any byte.

The text looks wrong. Tap the code page on the bottom bar, or hold a finger on the text, and pick another one. AUTO guesses it from the file.

Does the app send my files anywhere? No. It does not use the network at all: see the privacy policy.
