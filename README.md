# fondorn.github.io

The author's home page, and the site behind the store listings: dosview's
support page and privacy policy. Everything here goes, as is, into the public repository
`FonDorn/FonDorn.github.io`, served by GitHub Pages at
https://fondorn.github.io/:

- `/` — home page: photo, GitHub, LinkedIn, the apps
- `/dosview/` — support, the App Store "Support URL"
- `/dosview/privacy/` — privacy policy, linked from the stores and from About

`.nojekyll` makes Pages serve the files without Jekyll.
